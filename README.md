# Thai Sentiment Analysis

A Natural Language Processing (NLP) project for sentiment classification of Thai text.

## Project Overview

This project analyzes Thai text and classifies its sentiment into different categories using machine learning techniques.

The project covers the end-to-end data science workflow:

* Data preprocessing and Thai text cleaning
* Exploratory data analysis
* Feature extraction
* Model training and comparison
* Model evaluation

## Modules

* Python
* Pandas
* NumPy
* Scikit-learn
* PyThaiNLP
* Matplotlib
* Seaborn

## How to Run

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Then open and run:

```text
notebooks/experiment.ipynb
```

## Objective

The objective of this project is to explore and develop a machine learning approach for Thai sentiment analysis, from data preprocessing to model evaluation.
